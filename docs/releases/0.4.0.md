本次更新集中改进 AI 助手的长任务、多对话与子代理协作。

- **多对话并行与跨终端操作**：一段对话运行时可新建或切换另一段对话；Agent 可发现应用内打开的本机和 SSH 终端，选择目标执行命令或比较目录。
- **完整子代理对话**：支持并行委派，查看主代理给出的完整任务说明、工具调用、执行输出和报告；可向运行中的子代理追加消息，或继续已结束的任务。子代理沿用主代理的权限、记忆和终端资源能力。
- **等待期间继续交互**：命令和子代理等待时可追加指令、立即处理、暂停或结束等待，避免整段对话被占住；补强任务通知、保存失败重试和恢复流程。
- **执行通道与持续服务**：Agent 按任务选择页面 shell 或独立通道，异步等待与通道独立。开发服务器等持续服务支持启动检查、查看日志和停止，并可在子代理结束后继续运行。
- **网页搜索与读取**：新增 Tavily 搜索、DuckDuckGo 备用搜索及网页正文读取；可在 AI 设置中启用并配置 Tavily Key。
- **长任务与记忆**：新增全局/主机说明、自动记忆与管理界面；支持长上下文压缩、可恢复暂停、上下文占比及斜杠命令。
- **统一工具与消息界面**：工具卡片统一状态、折叠和操作；输出支持展开完整保留内容与复制，子代理拥有独立时间线；每轮任务显示结束时间和运行时长，用户消息支持拖选与整条复制。
- **状态与目录修复**：后台命令和子代理继承正确工作目录；读取日志不再误报原命令退出码 0；服务停止后显示当前停止状态，历史就绪证据保留在详情中。

### 升级说明

AI 请求中的问题、选取的终端上下文和工具结果不再自动脱敏，会发送到你配置的 AI 服务。网页工具可单独启用；对话保存和自动记忆可在设置中管理。

持续服务的就绪输出仅证明该日志出现；需要确认 HTTP 或端口可用性时，Agent 仍需进一步检查。应用重启不会自动重启此前的服务进程。
