本次更新扩展 AI 助手的模型协议与图片输入，并让主代理、子代理都能操作终端中的交互程序。

- **OpenAI Responses 协议**：新增 Responses 接入，支持工具调用、流式回复和上下文回放，与已有协议共用代理能力。
- **图片与截图输入**：对话支持添加图片和截图，主代理与子代理可使用图片附件；模型和服务端需支持图像输入。
- **向用户提问**：主代理、子代理可以提出问题并接收回答，支持等待回答或继续其他工作，再根据回答恢复任务。
- **通用 TUI 操作**：Agent 可读取当前终端画面、输入文字和按键，并执行程序支持的鼠标点击、滚动和拖拽。支持已有本机和 SSH 终端，可随时人工接管，允许继续后再交还控制。
- **独立交互终端**：Agent 可在本机或已有 SSH 连接中创建独立 PTY，后台运行而不占用原终端。任务入口提供查看和接管；收起保持运行，停止保留画面，关闭释放资源。子代理结束后，终端仍由主会话管理。
- **动态画面交互改进**：读屏裁剪与输入校验分离，支持明确的操作前置条件；输入后短暂观察，等待使用同一画面基准，未观察到变化时不自动重发按键。
- **统一对话界面**：调整 AI 模块为 Flyme 12 风格，显示模型提供的可折叠思考内容；消息时间和复制图标在悬浮时显示，回复用时常驻显示。连续终端操作可展开查看完整过程，状态明确区分已读取、已发送、条件满足、超时和接管。
- **交互细节修复**：移除续答前缀，无追加消息时不再占用交互栏空白；移除专用目录比较工具，目录比较等场景由通用多终端工具完成。

### 使用说明

独立 PTY 随应用生命周期运行，应用重启不会恢复其中的程序；停止 Agent 回复只交还终端控制，不等于停止程序。

TUI 的快捷键和操作含义由 Agent 根据画面与帮助判断。输入已发送或观察条件满足不代表业务操作成功；现有权限审批和人工接管机制继续生效。
