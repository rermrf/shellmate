# P6：效率工具 实施计划

目标：做出原型中的命令面板（⌘K）、快捷命令、发送确认、跨主机命令历史（⌃R）、广播输入、分屏、会话录制与回放、会话日志，以及设置窗口。工具栏和终端底栏里现在标着"P6 实现"的按钮全部接上。

AI 助手仍属于 P7，按钮继续禁用。设置里的"凭据与安全"（主密码加密库、Touch ID、闲置锁定）与"同步与备份"也属于 P7，本阶段只显示当前状态，选项禁用并注明"后续版本提供"。

原型参考：`docs/Shellmate 原型.html` 中的 `pal*`（命令面板）、`CMDS` / `cmdGroups` / `qc*`（快捷命令与发送确认）、`RISK`、`hs*`（历史）、`bc*`（广播）、`split*`（分屏）、`tabMenu`、`rec*` / `rv*` / `rp*` / `lg*`（录制、记录、回放、日志）、`stRowsMap`（设置）。截图（我从原型生成）：`scratchpad/shots/` 下的 `p6-pal.png`、`p6-hist.png`、`p6-split.png`、`p6-rv.png`、`p6-qc.png`、`cmds.png`、`bc.png`、`settings.png`。

## 技术决定（已定，不要改动）

| 项 | 决定 |
|---|---|
| ⌘K | 改为打开**命令面板**（原型如此）；侧边栏搜索框仍可点击使用，窄栏的搜索按钮改为打开命令面板 |
| 命令面板内容 | 按原型分组：快速连接（输入 `user@host[:port]` 时，临时会话不写入主机列表）、主机（有输入时搜索全部，无输入时"最近主机"4 个）、切换会话、快捷命令、操作（打开本地终端 ⌘T、新建连接、复制当前会话 ⇧⌘T、分屏 / 取消分屏、打开文件 / 监控 / 端口转发、切换明暗主题、收起 / 展开侧边栏 ⌃⌘S、导入 ~/.ssh/config、打开设置、搜索命令历史 ⌃R、会话记录与回放）。模糊匹配，最多 12 项，↑↓ 选择、↵ 执行、esc 关闭。AI 助手项不出现 |
| 快捷命令 | 存 SQLite（分组 + 名称 + 命令 + 排序），工具栏"快捷命令"打开右侧抽屉（原型 `cmds.png`），"管理"打开增删改与排序。**不预置任何命令**：空状态提供"添加示例命令"（原型的 系统 / 服务 / Docker 三组），用户点了才写入 |
| 发送确认（qc） | 快捷命令、历史命令、广播中的危险命令，都先弹确认框（原型 `p6-qc.png`）：名称、"发送到当前会话" / "广播到 N 个会话"、**可编辑**的命令、目标会话标签（生产主机标"生产"）、危险时红色说明与"确认执行"按钮；回车执行、esc 取消 |
| 危险命令 | 沿用原型 `RISK` 规则（sudo、rm、reboot、shutdown、kill / pkill / killall、mkfs、dd、truncate、chmod、chown、iptables、`systemctl stop/restart/reload/disable`、`docker rm/stop/kill/image prune/system prune`、`drop table/database`），纯函数并有测试。"生产主机"：主机的分组名或标签含"生产"或 `prod`（不分大小写） |
| 发送方式 | 命令按"粘贴 + 回车"送入会话：shell 开了括号粘贴就用括号粘贴，再单独发 `\r`；多行命令不会被逐行执行 |
| 命令历史的来源 | **从终端画面取，而不是记键盘输入**：在主屏（非 alt screen）按回车时，取"本行自上次回车后第一次按键时光标所在位置"到行尾（含自动换行的续行）的文字。shell 发出 OSC 133 语义标记时以标记为准。好处：上箭头调出的历史、Tab 补全的结果都是最终文字；**不回显的输入（密码）不会被记录**。不记：空行、单个字符、以空格开头的行（与 `HISTCONTROL=ignorespace` 一致）、看起来带凭据的行（如 `-p<密码>`、`PASSWORD=`、`TOKEN=`、`curl -u user:pass`，规则列表有测试）；连续重复只记一次 |
| 命令历史的存储 | 本机 SQLite，每条：主机（或"本机"）、命令、当时目录（有 OSC 7 时）、时间；最多 2 万条，超出删最旧。设置里可关闭记录、可清空。**不加密**（主密码加密库属于 P7），所以面板底部文字如实写"历史保存在本机，可在设置中关闭"，不写原型里的"加密保存" |
| ⌃R | 终端获得焦点时 ⌃R 打开 Shellmate 的历史面板（原型 `p6-hist.png`：`(reverse-i-search)`、全部会话 / 当前主机、最多 8 条、↑↓ 或 ⌃R 切换、↵ 打开发送确认、esc 关闭）。设置里可关闭此快捷键，关闭后 ⌃R 交给 shell 自己的反向搜索 |
| 广播 | 按原型是**按行广播**：工具栏"广播"打开抽屉里的广播区（开关 + 会话勾选列表，只有已连接的会话可勾选），开启后被勾选的标签显示"广播"徽标，终端底部出现广播输入栏（"广播 → N 个会话"、输入框、发送）。输入栏的补全来自历史与快捷命令（Tab 采用）。危险命令走发送确认。广播开启时，快捷命令和历史命令也发往全部勾选的会话。不做逐键镜像 |
| 分屏 | 按原型：终端视图左右（可改上下）两个窗格，各有标题栏（会话名 ▾ 切换窗格里的会话、尺寸、"输入焦点"标记），点击窗格切换焦点；发送确认等操作作用于焦点窗格。只做两个窗格、各占一半。分屏里的会话被关掉时退出分屏 |
| 标签列表 | 标签多到放不下时，标签栏显示"N 个标签 ▾"，点开列出全部标签（状态点、名称、协议 / 重连中），点选切换 |
| 录制 | 终端底栏"● 录制"开始 / 停止，录制中显示红色"REC 00:12 · .cast"。格式为 asciinema v2：只记**输出**（`o`）与尺寸变化（`r`），**不记输入**；边录边写文件，不在内存里攒。停止后提示"已保存 .cast · 可在「记录」中回放"。文件放 `~/Library/Application Support/Shellmate/recordings/`（元数据：标题、主机、开始时间、时长、大小存 SQLite，标题可改） |
| 回放 | "记录"窗口（原型 `p6-rv.png`）的"录制回放"页：列表（标题、主机 · 时间、时长 · 大小）、播放器（播放 / 暂停 / 重播、进度条可点击跳转、1× / 2× / 4×、复制当前画面文本、导出 .cast（保存对话框）、删除（确认））。播放器用 `shellmate-term` 的同一套终端模拟与绘制；空闲超过 2 秒的停顿压缩为 2 秒；跳转时从头快速重放到目标时刻（大文件可用检查点加速） |
| 会话日志 | 设置里"保存会话日志"开启后（默认关），每个会话把**主屏上已定稿的行**（滚出屏幕的行，以及会话结束时屏幕上剩下的行）连同时间写入 `~/Library/Logs/Shellmate/<主机>/<日期>.log`，纯文本、无控制序列；alt screen（vim、top 等）的内容不写。"记录"窗口的"会话日志"页：按主机与日期列出、查看（搜索过滤）、"在 Finder 中显示" |
| 设置窗口 | 按原型（`settings.png`）：左侧分区 凭据与安全、同步与备份、终端、本地终端、连接与保活。**只放与已实现行为对应的开关**；P7 的选项显示但禁用。终端区：选中即复制、右键粘贴、括号粘贴模式、记录命令历史 + 清空、⌃R 打开 Shellmate 历史、保存会话日志、自动录制所有会话（默认关）。本地终端与连接区：只放当前代码里已有、且值得让用户改的行为（实现前列出给我确认）。设置存在现有的 `settings` 表 |
| 存储与迁移 | 历史、快捷命令、录制元数据进主机库，schema 升到 v4（带迁移测试；旧版程序打不开 v4 库，报告里注明） |
| 测试不碰真实数据 | 录制与日志目录都可用环境变量改到临时目录（如 `SHELLMATE_DATA_DIR`、`SHELLMATE_LOG_DIR`）；测试和截图一律用临时目录与 `SHELLMATE_DB`，不写用户真实的 Application Support、Logs 和主机库 |

## 里程碑（每个里程碑单独提交，完成后停下等待 review）

### M1：命令面板、快捷命令、发送确认、命令历史
- 存储：v4 迁移，`snippets`、`history` 表与增删改查、上限清理。
- 命令面板（⌘K）、快捷命令抽屉与管理、发送确认、危险命令规则、发送方式。
- 历史：画面取词（含 OSC 133 路径）、过滤规则、⌃R 面板、"当前主机 / 全部会话"。
- **测试**：模型单测（面板匹配与排序、分组、快速连接解析、危险规则、生产判定、凭据过滤规则）；终端层测试——向模拟终端喂真实 shell 的输出并模拟按键，验证：普通命令、上箭头调出的命令、Tab 补全后的命令、自动换行的长命令、不回显输入（密码）不被记录、alt screen 中不记录、以空格开头不记录、OSC 133 路径；存储迁移与上限测试；截图对照原型（浅色 / 深色）；真实服务器上：在 `shellmate-e2e` 与 `shellmate-mon` 的终端里执行若干命令后，⌃R 能找到、且来源主机正确；从快捷命令发送 `uptime` 得到输出。

### M2：广播、分屏、标签列表
- 广播抽屉、勾选、广播输入栏与补全、标签徽标、与发送确认的配合。

- 标签列表菜单。
- **测试**：模型单测（目标会话的计算：只含已连接的；断线的自动排除；危险命令走确认）；真实服务器上：同时向两台测试机广播 `hostname` 各收到一次且只一次、一台断线时只发给另一台；分屏中两个会话各自尺寸正确（远端 `stty size` 与窗格一致）、焦点切换后发送去对的窗格；截图对照原型。

### M3：录制与回放、会话日志、设置
- 录制（底栏按钮、计时、边录边写、尺寸变化）；"记录"窗口的回放与日志两页；设置窗口。
- **测试**：.cast 写读往返（含 UTF-8 被切在两个数据块之间、尺寸变化）、与 asciinema 格式一致（用官方格式说明里的样例校验）；播放器跳转后画面与顺序播放到同一时刻一致；空闲压缩；日志：进度条（`\r` 覆盖）只记最终结果、alt screen 不记、跨日期切换文件；设置的读写与各开关真实生效；截图对照原型；真实服务器上：录一段 `ls` + `top`（alt screen）再回放、导出的 .cast 能被解析。

## M2 review 结论（2026-11-16，通过）

提交：本节之前的一个提交（M2）。
