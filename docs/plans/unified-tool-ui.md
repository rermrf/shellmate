# 统一工具调用界面

状态：已实现。2026-11-26，代码基线 `db4e2c0`。

## 展示规则

- 主对话、子代理对话、命令审批及委派子任务复用同一个工具卡片外壳：工具标题与状态行、输入摘要、结果/执行方式摘要、可展开内容、底部操作。
- 标题点击只负责展开/收起。子任务的“查看对话 →”单独导航；追加消息沿用原子代理页。收起时搜索不展开来源列表，命令不展开输出，子任务不展开完整委派/报告。
- 展开后按“输入”“结果”组织。命令展示实际批准执行的命令、目录（已记录时）、执行说明和输出；搜索保留来源列表与链接；网页保留正文查看器；子任务保留委派原文和进展/报告。原始 JSON 是次级详情。
- 复制输入/命令、复制输出/结果和停止/取消操作集中在底部。输出阅读器嵌入工具卡时不再提供第二层折叠或重复复制按钮，保留全文、选择、滚动、跳转最新和错误重试能力。
- 等待批准强制展开，批准/编辑/拒绝保持可见，高危说明保留。通过后沿用同一工具身份和展开状态，完成后更新结果。主/子代理的同一种工具采用相同布局。

## 状态与生命周期

- 统一状态文字与色彩：等待批准、运行中、等待结果、已完成、失败、已取消、已拒绝、已暂停；恢复历史且缺少后台进程状态时显示状态未知，不假装仍在运行或成功完成。
- 后台/终端是执行方式，放在摘要，不能替代结果状态。命令退出状态结合已有成功判定，子代理以运行器状态为准；子代理启动工具返回不等于子任务结束。
- 仅展示已有可靠耗时：进行中的命令用原进程时钟；已完成命令使用记录耗时；子任务用自身时长。没有可靠时长的通用工具不填 0 秒。
- 卡片身份包含会话、线程和调用身份。运行中的临时身份在日志落地后保持映射；provider 复用 call ID 时新旧调用互不覆盖。子代理增量日志沿用语义日志的 ID 规范化规则，避免结束前后切换身份。
- 完整输出实体与卡片身份一致，展开、阅读和选择状态跨运行/完成保留。任务条“查看输出”定位并展开主线程对应卡片；子任务停止按自身注册表路由。
- 工具数据/权限不变：界面统一不重新执行工具，不新增授权，不重新请求历史数据。
