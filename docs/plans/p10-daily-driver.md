# P10 日常主力终端：字号缩放、后台提醒、恢复会话（0.3.0）

目标：让 Shellmate 适合当作每天的主力终端。三个功能合在一起发 0.3.0，连同已经完成的等宽标签。

- **M1** 字号缩放、帮助菜单与快捷键一览
- **M2** 后台标签提醒、系统通知、终端焦点报告
- **M3** 重启后恢复窗口和会话

每个里程碑由 Sonnet 5.5 子代理实现，Claude 按第 6 节验收后再开始下一个。Shellmate 是**通用终端**，不为某个程序写专门的逻辑或文案，只支持通用的终端约定。

---

## 0. 已确定的决策（用户 2026-11-23）

| 问题 | 决定 |
|---|---|
| 系统通知什么时候弹 | 只在 Shellmate 不在前台，或会话所在窗口被隐藏时弹；用户在 Shellmate 里时只亮标签提醒点 |
| 本机长命令完成提醒 | 做：本机会话里前台命令运行 ≥ 30 秒，在后台结束时提醒 |
| 针对某个程序的配置说明 | 不做。只支持通用约定：响铃（BEL）、OSC 9、OSC 777 |
| 远程会话怎么恢复 | 每个窗口只立刻连接当前显示的标签，其他标签第一次被切到时再连 |
| 恢复终端里的屏幕内容 | 先不做，只恢复会话本身 |
| 字号缩放的范围 | 只作用于当前窗口，临时生效；⌘0 回到默认字号；默认字号在设置里改 |

## 1. 现状（2026-11-23 查代码）

- 终端字号写死在 `theme.rs` 的 `terminal_style()`：13 pt，行高 20/13。设置页「终端」里的「字体」一行只能看不能改。
- 每个 `TerminalView` 持有自己的 `TerminalStyle`，`set_style` 可以更新。目前切换深色外观（`toggle_theme`）时，会把同一份全局样式推给所有窗口的所有会话。
- 「显示」菜单里没有缩放项，也没有「帮助」菜单。⌘= / ⌘− / ⌘0 / ⌘/ 都没有被占用。
- `shellmate-term` 已经把响铃转成了 `TerminalEvent::Bell`，但 `shellmate` 应用层没有处理。
- OSC 9 和 OSC 777 完全不认。现有一个按字节扫描 OSC 7 的 `osc7.rs`，可以照着写。
- 没有实现终端焦点报告（DECSET 1004）。
- gpui 自带系统通知接口：
  - `cx.show_system_notification(SystemNotification { tag, title, body, actions })`
  - `cx.dismiss_system_notification(tag)`
  - `cx.on_system_notification_response(...)`，用户点通知后把 tag 带回来
  - 测试上下文里有 `shown_system_notifications`、`simulate_system_notification_response`
  - 必须在打包好的 `.app` 里才能真正弹出；`cargo run` 时不可用，记一条日志即可。
- 菜单栏图标已经有「需要注意」状态（`status_item/model.rs` 的 `attention()`），目前只看 SSH 失败一类的状态。
- 没有任何会话恢复。现有的「+ 新建同类会话」（`workspace/ssh.rs` 的 `duplicate_active`）已经实现了按类型重开：
  - 本机：按目录打开；
  - SSH：按主机连接，再打入 `cd -- '<目录>' && clear`；
  - Telnet / Mosh / 串口：按主机打开。
  - 恢复要复用这套逻辑，不要另写一份。
- 设置存在 `shellmate-store` 的设置表（`setting` / `set_setting`，键值对）。本期**不改数据库结构**。
- 设置页的分区：凭据与安全、同步与备份、终端、本地终端、连接与保活、AI 助手、软件更新。

## 2. M1：字号缩放、帮助菜单与快捷键一览

### 2.1 默认字号

- 新设置项「终端字号」，范围 9–28 pt，步长 1，默认 13。存为 `terminal.font_size`。
- 放在「设置 › 终端」：
  - 把原来只读的「字体」一行拆成两行：字体名只读；字号可改，用 − / 数值 / + 的小步进控件，沿用现有组件风格。
  - 行高比例保持 20/13。
- `terminal_style()` 返回默认字号。改默认字号时，所有没有临时缩放的窗口立即跟着变。

### 2.2 窗口内临时缩放

- `Workspace` 增加 `font_size: Option<f32>`，`None` 表示用默认字号。不保存，窗口关闭就没了，重启也不恢复。
- 三个动作：
  - 「放大」：同时绑定 `cmd-=` 和 `cmd-+`；
  - 「缩小」：`cmd--`；
  - 「实际大小」：`cmd-0`，回到默认字号。
- 每次 ±1 pt，限制在 9–28。到了边界再按就不变，不报错。
- 作用范围：这个窗口里所有会话的终端视图，包括分屏。
- **会话移到别的窗口时**（`attach_session`），改用目标窗口的字号。
- **新建会话时**（本机、SSH、Telnet/Mosh/串口），用所在窗口的字号。增加一个 `Workspace::terminal_style(cx)`，返回全局样式加上本窗口的字号，替换现有直接调用 `cx.terminal_style()` 建视图的地方。
- **`toggle_theme` 要改**：每个窗口用自己的字号，不能把全局样式统一推给所有窗口。
- 字号变了，终端行列数会跟着变，要确认会正确通知 PTY 和远端改尺寸，并补一个测试。
- 录制回放面板和演示场景保持默认字号，不受缩放影响。
- 「显示」菜单在面板切换那组之后加「放大 / 缩小 / 实际大小」。

### 2.3 帮助菜单

新增顶层菜单「帮助」，放在「窗口」之后：
- 「键盘快捷键」（⌘/）：打开快捷键一览。
- 「打开日志文件夹」：在访达里打开当前的日志目录，要尊重 `SHELLMATE_LOG_DIR`。
- 「项目主页」：用浏览器打开 `https://github.com/rermrf/shellmate`。

### 2.4 快捷键一览

- 一个模态对话框，沿用 `dialogs/` 里现有的对话框样式。
- 按类别分组：会话与标签、窗口、显示、编辑与终端、工具。每行左边是说明，右边是按键，按键用 ⌘⇧⌥⌃ 符号。
- **不能和实际绑定脱节**：
  - 菜单动作的快捷键从同一份定义生成；
  - 写在 `key_down` 里的按键（⌘1–⌘9）和终端内按键（⌘F、⌘G 等）手动列出；
  - 加一个单元测试：一览里的每个按键要么确实绑定了，要么在一份显式的「手动处理」清单里；每个注册了的菜单快捷键都出现在一览里。

### 2.5 演示场景与调试开关

- 新增演示场景 `shortcuts`：打开快捷键一览。
- 新增 `SHELLMATE_DEBUG_ZOOM_AFTER=<秒>:<步数>`：调用生产代码的放大或缩小动作（负数为缩小）。日志里打印字号和终端行列数。
- `set-term` 系列场景会因为字号控件而改变，这是预期的；其他场景必须逐像素不变。

## 3. M2：后台标签提醒、系统通知、焦点报告

### 3.1 识别通知（`shellmate-term`）

在终端输出的字节流上新增一个扫描器，写法参照 `osc7.rs`。它对所有后端（本机、SSH、Mosh、Telnet、串口）都生效。

- **OSC 9**：`ESC ] 9 ; <文本> (BEL | ESC \)`。
  - 文本以「数字后跟 `;` 或直接结束」开头的（例如 `9;4;1;50` 进度条），属于 ConEmu 的子命令，**不是通知**，要忽略。
- **OSC 777**：`ESC ] 777 ; notify ; <标题> ; <内容> (BEL | ESC \)`。其他子命令忽略。
- **安全处理**：
  - 每条最多 1 KiB，超过就截断；
  - 去掉控制字符；
  - 序列被拆在两次读取之间时也要能识别。
- 新增事件 `TerminalEvent::Notify { title: Option<String>, body: String }`。响铃沿用已有的 `TerminalEvent::Bell`。
- 这两种序列交给 alacritty 后本来就会被忽略，屏幕上不会多出任何东西。

### 3.2 终端焦点报告（DECSET 1004）

- 程序开启 `?1004h` 后：
  - 终端获得焦点时发 `ESC [ I`，失去焦点时发 `ESC [ O`；
  - 同一状态不重复发；
  - 开启的那一刻如果当前没有焦点，立即补发一次 `ESC [ O`。
- 「有焦点」的定义：这个终端视图是窗口里的焦点元素，**并且**窗口是活动窗口，**并且**应用在前台。
- 会触发变化的情况：
  - 切换标签；
  - 分屏里切换焦点；
  - 窗口激活或失活；
  - 应用切到后台或回到前台；
  - 窗口隐藏；
  - 会话移到其他窗口。

### 3.3 「正在看」与提醒标记

- 一个会话「正在被看」的条件：它是所在窗口当前的标签，或者分屏里显示着它；**并且**窗口没有隐藏、是活动窗口；**并且**应用在前台。
- 收到响铃、通知或长命令完成时：
  - 如果正在被看，**什么都不做**，本期不做视觉响铃；
  - 否则给会话打上提醒标记，记下种类（响铃、通知内容、命令完成）和时间。
- 会话变成「正在被看」时，清除提醒标记，同时撤回它的系统通知（`dismiss_system_notification`）。
- **标签上的显示**：
  - 有提醒的标签，在标题后面显示一个强调色小圆点，直径约 6 pt，放在徽标和 × 之前；
  - 等宽标签的宽度计算（`tabs::Content`）要把这个圆点算进去；
  - 标签太窄时，圆点优先于「广播」标签保留。
- **「N 个会话 ▾」菜单**：
  - 被收起的标签里有提醒时，触发按钮旁也显示小圆点；
  - 菜单里对应的行也要标出来。

### 3.4 系统通知

- 只在两种情况下弹：Shellmate 不在前台，或者会话所在窗口被隐藏（收到菜单栏的状态）。
- 内容：
  - **标题**：OSC 777 带了标题就用它，否则用标签标题；
  - **正文**：
    - 收到通知：用通知内容；
    - 响铃：「需要你的注意」；
    - 命令完成：「命令已完成：<程序名>（用时 X 分 Y 秒）」。
- tag 为 `session-<全局会话 ID>`。同一个会话再来通知时用同一个 tag 替换，不会堆叠。
- 合并：同一会话 10 秒内最多发一次；连续响铃只算一次。
- 点通知（`on_system_notification_response`）时：
  1. 显示窗口，走已有的重新显示路径：需要时切回 Regular 激活策略，再 `makeKeyAndOrderFront`；
  2. 切到对应的标签，让终端获得焦点；
  3. 清除提醒标记。
- 会话已经关闭的话，只激活应用。

### 3.5 菜单栏与 Dock

- 菜单栏图标的「需要注意」也要算上带提醒标记的会话。菜单里的会话列表标出这些会话。
- Dock 图标角标显示带提醒的会话数量，为 0 时清除。

### 3.6 本机长命令完成提醒

- 只对本机会话。利用现在每秒一次的前台进程轮询（`titles.rs` 的 `refresh_local_title` 所在的那个 tick）。
- 前台进程从「shell 以外的程序」回到 shell 时，如果这个程序已经运行 ≥ 30 秒，并且会话没有被看，就打「命令完成」提醒。
- 用时从第一次看到这个前台进程起算，误差 1 秒以内可以接受。
- 判断逻辑写成纯函数，方便单测。

### 3.7 设置（「设置 › 终端」）

| 设置项 | 默认 | 说明 |
|---|---|---|
| 后台标签提醒 | 开 | 标签小圆点、菜单栏、Dock 角标 |
| 系统通知 | 开 | 说明文字：「仅在 Shellmate 不在前台时发送」；关掉「后台标签提醒」时一并失效 |
| 本机长命令完成提醒 | 开 | 说明文字：「本机命令运行超过 30 秒、在后台结束时提醒」 |

### 3.8 测试、演示场景与调试开关

- **单元测试**：
  - 扫描器：BEL 和 ST 两种结尾、跨块拆分、ConEmu 排除、777 解析、长度上限、控制字符；
  - 焦点报告的编码和去重；
  - 「正在看」的判定、提醒的打上和清除、10 秒合并；
  - 长命令判定。
- **gpui 测试**：
  - 用 `shown_system_notifications` 验证通知只在应用不在前台时发出；
  - 用 `simulate_system_notification_response` 验证点通知后切到正确的会话。
- **新演示场景 `tab-attention`**：有一个后台标签带提醒点，另有一个提醒标签被收进了「N 个会话 ▾」。
- **新调试开关**：
  - `SHELLMATE_DEBUG_NOTIFY_AFTER=<秒>`：打开第二个本机标签后切回第一个，向第二个标签的 shell 写入 `printf '\033]9;debug-notify\007'`，走完整的生产链路，日志里记录提醒和通知。
  - `SHELLMATE_DEBUG_FOCUS_LOG=1`：打印每次焦点报告。

## 4. M3：重启后恢复窗口和会话

### 4.1 设置

「设置 › 连接与保活」加「启动时恢复上次的窗口和标签」，默认开，放在「关闭窗口时」的设置附近。关掉时立即删除已保存的快照。

### 4.2 快照内容

快照用 JSON 存进设置表的 `session_restore` 键，带版本号 `v: 1`。

- **每个窗口**：
  - 全局坐标下的位置和大小；
  - 侧栏是否展开；
  - 标签顺序；
  - 当前标签。
  - 临时字号不保存。
- **每个会话**：
  - 类型和标识：
    - 本机：当前目录，取前台进程或 shell 的工作目录；
    - SSH / Mosh / Telnet / 串口：主机 ID；
    - 快速连接（不在主机列表里）：`user@host:port`；
  - 远端目录：只在远端 shell 用 OSC 7 报告过时才有；
  - 当前面板：终端、文件、端口转发或监控。
- **窗口顺序**：按最近激活排序，恢复后最近用过的窗口在最前面。
- **不保存**：屏幕内容、分屏、AI 对话、草稿。

### 4.3 什么时候保存

- 有变化时只标记为「待保存」，最多每 5 秒写一次。会触发的变化：
  - 开、关、移动、排序标签；
  - 切换当前标签；
  - 开关窗口；
  - 移动窗口或改变大小；
  - 切换面板。
- 写入时读取当时的实际目录。
- 退出时（`on_app_quit`）同步写一次；应用内更新重启之前也写一次。
- 不保存的情况：
  - 恢复进行中；
  - 设置关闭；
  - 演示场景运行（`SHELLMATE_DEMO`）；
  - 测试。

### 4.4 启动时恢复

- **条件**：设置开着，并且有一份能解析的快照。这时用快照代替原来「第一个窗口自动开一个本机终端」的行为。快照为空或解析失败时，按原来的方式启动，并记一条日志。
- **窗口**：
  - 原来的位置和任何一块现有屏幕都不相交时，放到主屏居中；
  - 大小不小于最小窗口尺寸。
- **本机会话**：在原目录新开 shell；目录不存在就用 home。
- **SSH / Mosh / Telnet（决策：只连当前标签）**：
  - 每个窗口的当前标签立即连接；
  - 其他标签先显示为「未连接」：圆点灰色，终端区提示「切换到这个标签时连接」；第一次被切到时才连接；
  - 连上后，如果有远端目录，像「+」一样打入 `cd -- '<目录>' && clear`。
- **串口**：永远不自动连，切到时也只显示「按回车连接」，因为设备可能已经拔掉了。
- **找不到的主机**：跳过，在第一个窗口里用一条应用内通知列出名字：「N 个主机已删除，未恢复：…」。
- 凭据库锁着时，连接时照常弹出解锁。
- **从访达启动**：如果启动是因为访达「进入 Shellmate」或把文件夹拖到图标上，先恢复，再在最前面的窗口里打开那个目录。

### 4.5 和退出、更新的配合

- 退出确认（`confirm_quit`）和「安装并重启」的确认，在恢复设置开着时，提示里加一句：「重启后会恢复窗口和标签，正在运行的程序会结束」。
- 「关闭窗口时 = 保持运行」的隐藏状态不恢复：恢复出来的窗口一律显示。

### 4.6 测试与调试开关

- **单元测试**：
  - 快照的序列化往返和版本处理；
  - 从界面状态生成快照（纯函数）；
  - 「快照 + 现有主机 + 屏幕 → 恢复计划」（纯函数），覆盖主机已删、目录不存在、屏幕不在、快速连接、串口；
  - 待连接标签的状态转换；
  - 保存节流。
- **调试开关**：
  - `SHELLMATE_DEBUG_RESTORE_FROM=<json 文件>`：用指定快照启动，必须配合隔离的 `SHELLMATE_DB` / `SHELLMATE_DATA_DIR`；
  - `SHELLMATE_DEBUG_SNAPSHOT_TO=<文件>`：每次写快照时同时写一份到这个文件。
- 用 `shellmate-e2e` 容器（127.0.0.1:2222）验证 SSH 会话的待连接和切到时再连。
