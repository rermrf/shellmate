# 界面还原（2026-11-16）

用户要求界面与 `docs/Shellmate 原型.html` 像素级一致。原型里没有的界面，按现有风格结合 Flyme OS 12 的风格补齐：低饱和配色，大圆角（卡片 18–22、内层 14、控件 10–12），留白按 4px 网格，只用细分隔线，柔和阴影，短而顺的过渡动画。

## 工具

工具都在会话的 scratchpad 目录 `parity/` 下：

- **原型基准**：`mkscenes.py` + `capture.sh` 用无头 Chrome 按点击顺序重现原型的 33 个界面状态，每个状态都有浅色和深色。截图为 2× 尺寸；同时导出每个元素的位置、字号、颜色、圆角和阴影。为了让截图稳定，固定了随机数和计时器，深色直接以深色启动。
- **应用对照**：调试构建里的 `SHELLMATE_DEMO=proto:<界面>` 用原型的同一份数据，把应用摆成同样的状态（`@宽x高` 可指定窗口大小）。`appshot.sh` 截应用的图，生成并排图、差异热图和叠加图；`report.sh` 按元素算出偏移量和残差。
- **压力场景**：`proto:stress-*` 用真实环境里最坏的数据检查布局：7 位 PID、超长名称、16 核、9 个标签、TB 级数值。在 1776×901 和 1100×700 下都要检查。

## 刻意保留的差异

- **背景模糊**：原型对话框背后有 3–6px 模糊，gpui 不支持，只保留遮罩色。
- **窗口按钮**：左上角红黄绿是 macOS 原生按钮，大小和间距与原型的 CSS 圆点不同。
- **文字渲染**：浏览器和 Core Text 的渲染有零点几像素的差别；gpui 没有 CSS 字距（-0.3px 等）。
- **终端**：`●`、中日韩文字和长行严格按终端字符格排布，不模仿浏览器的宽度。
- **编辑器**：原型里代码比行号低两行，属于原型自身的显示问题，不照搬；语法高亮是真实的语法着色，颜色与原型的简单正则着色不同。
- **randomart、监控曲线、排序**：按真实数据计算，不照搬原型的假数据。
- **文案**：保留计划里刻意改过的、更如实的文案，例如「历史保存在本机，可在设置中关闭」「经 docker 命令 · 事件实时推送」。P7 的功能显示为不可用。
- **窄栏浅色**：原型浅色窄栏界面里，主区域没有左移（深色界面会左移）。应用在两种主题下都会左移，以收回空间。

## 暂缓（用户决定）

- **容器端口转发的显示**：转发显示为「127.0.0.1:P → 127.0.0.1:P」，右边是服务器上的地址。功能正常，原型也是这样设计的，但看起来像本机连本机。用户说先不改。
