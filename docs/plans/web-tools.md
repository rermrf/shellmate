# 网页搜索与正文读取

状态：已实现。2026-11-26，代码基线 `ec2f930`。

## 范围与配置

- `web_search`：Tavily API Key 为主，固定 Basic Search，关闭 auto_parameters、额外 AI 答案和原始正文；DuckDuckGo Lite 为可关闭的备用搜索。
- `web_fetch`：由本机直接获取公开 HTTP(S) 页面，提取正文。没有 SearXNG、Jina 或免 Key Tavily 实现。
- AI 设置新增“网页搜索与读取”开关、Tavily Key 保存/替换/移除、DuckDuckGo 备用开关。网页工具默认关闭；搜索需要 Tavily Key，读取网页不需要搜索 Key。密钥使用原有 CredentialStore，普通设置表及模型日志不保存密钥。
- 使用 Tavily 的免费账户 Key；服务配额/计费由 Tavily 账户决定。应用固定使用 Basic，遇到限额不充值、不切换更高费用模式。DuckDuckGo 可能因限流或验证不可用。

## 执行与数据

- 网页能力独立于 terminal/background 执行能力；未绑定终端时也能使用。主代理和子代理使用同一搜索配置、缓存与网络服务。`/btw` 仍不提供工具。
- Tavily HTTP 401/403 明确报 Key 错误；429/432/433、5xx 或传输失败可使用 DuckDuckGo 备用。没有结果不会转成失败或反复查询。备用请求不携带 Tavily 密钥。
- 参数：搜索词、1–10 个结果、可选域名过滤；读取 URL、offset 和每段字符数。搜索统一返回标题、URL、摘要、服务来源、搜索时间和缓存标记；读取返回最终 URL、标题、正文片段、总字符数、next_offset、读取时间和缓存标记。
- 同一会话及其子任务共享最多 3 个在途网页操作；搜索请求串行去重。缓存最多 16 项、10 分钟。分页缓存过期会要求从 offset=0 重读，不拼接不同版本正文。
- 支持 HTML、纯文本、Markdown、JSON、XML。正文移除导航、脚本、表单等，保留标题/段落/代码/链接。页面不执行 JavaScript，不使用浏览器登录状态，不处理 PDF 等二进制文件。
- 请求只访问公开地址；URL、每次跳转和实际 DNS 结果均校验，解析后地址直接交给连接器，避免绕过检查。不会向网页转发 Tavily Key 或终端凭据；搜索 API 不跟随重定向。使用本机直连，不读取环境代理配置。
- 连接超时 8 秒，单次请求 25 秒，整个操作 55 秒，最多 4 次跳转，响应上限 2 MiB。超时、验证页面、无正文、类型不支持和超限都有明确错误，不伪造成功。
- 立即处理/停止回复会取消在途网页请求并记录工具结果；取消子任务或销毁执行循环也释放网络 future。网页调用计入已有工具步数。
- 搜索结果和正文片段作为结构化 JSON 保存在普通 Step 日志中，历史查看不联网。完整已提取正文使用原有输出文件体系保存，用户可展开全文；保存关闭及会话删除沿用原有清理策略。

## 界面

主、子对话共用“搜索网页”“读取网页”卡片。搜索默认展示两条来源，点击“展开全部来源”显示完整列表；标题在浏览器打开，摘要可选择复制。备用搜索和缓存有明确标记。读取卡片显示标题、读取时间和正文总字符数，展开使用原有全文阅读器。错误状态保留原因，运行中显示查询词或 URL。沿用现有 palette、圆角、字体及窄窗口换行。
