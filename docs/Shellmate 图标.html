从 1c「本机与远端」简化而来：去掉渐变和投影，只留两个错位的圆角方块和 >_。按 macOS 模板图像来画——单色加透明度，浅色、深色菜单栏和点开时的高亮都由系统自动处理。每个方案都配了三种连接状态，下方的菜单栏是实际大小。

交付规格
格式 模板图像（Template Image）：只用黑色和透明度。macOS 会忽略颜色，自动适配浅色、深色菜单栏和点开时的高亮，不需要单独做深色版。
尺寸 16×16pt。导出一份 PDF 或 SVG 矢量，或者 PNG 两张：16px（@1x）和 32px（@2x）。菜单栏高 24pt，图标最高不能超过 22pt。
线宽与圆角 线宽 1.5pt（@2x 下 3px，对齐像素）。圆角是方块边长的 25%，和 1c 同比例；两个方块错开 10/22，层间留 1pt 缝。
状态 只靠形状和透明度区分，不用颜色：无连接时远端方块降到 35%（系统禁用态的惯例）；需要处理时远端右上角换成圆点。
代码里 NSImage 的 isTemplate 设为 true，或者让文件名以 Template 结尾（StatusTemplate.png / StatusTemplate@2x.png）。用 Rust 的 tray-icon crate 时对应 with_icon_as_template(true)。
